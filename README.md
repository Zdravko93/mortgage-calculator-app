## 📖 Overview

A fully responsive and interactive mortgage repayment calculator designed to provide users with accurate repayment estimates based on loan amount, term, and interest rate.

### ⭐ Features

- **GSAP animations** – Smooth transitions for page load, form interactions, and the author section.
- **Form validation** – Clear error messages for missing or invalid inputs.
- **Responsive design** – Works seamlessly across desktop, tablet, and mobile.
- **Accurate mortgage calculations** – Outputs monthly and total repayment amounts.
- **Clean, semantic HTML structure** — Helpful for SEO and accessibility.

### ♿ Accessibility

- Proper HTML semantics ensure strong screen-reader compatibility.
- All form inputs include labels and descriptive error messages.
- Accessible focus states and keyboard navigation.
- ARIA attributes where appropriate.

### 🎯 The Challenge

Users should be able to:

- Enter mortgage amount, term, and interest rate.
- Choose between repayment or interest-only mortgages.
- View the monthly and total repayment results.
- Receive feedback for invalid or incomplete inputs.
- Use the tool comfortably on any screen size.

## Installation Instructions

1. Clone the repository to your local machine using Git:
   ```bash
   git clone https://github.com/Zdravko93/mortgage-calculator-app.git
   ```
2. Navigate to the project directory:
   ```bash
   cd mortgage-calculator-app
   ```
3. Open `index.html` in your preferred browser.

   - Optional: Use a local server (e.g., Live Server in VS Code) for the best experience.

4. Modify and experiment with the code as you like.
